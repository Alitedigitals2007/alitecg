# alitecg

Alotedigitals contact gain platform — WhatsApp contact verification and VCF generation.

- Paid options: ₦500 verification / ₦1,500 full VCF purchase (manual receipt review)
- Tracking codes + status check page
- Admin dashboard: review proofs, approve/reject, download approved VCF
- Admin settings: update WhatsApp channel & group links
- Neon PostgreSQL storage, optional Telegram notifications

## Quick start

```bash
npm install
npm start
```

Configure `.env` (see `.env.example`), then visit `http://localhost:3000`.
