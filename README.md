# alitecg

Alite Digitals contact gain platform — WhatsApp contact verification and VCF generation.

- Contact gain: free task (follow channel + share screenshots) or ₦500 payment
- Buy VCF: standalone ₦1,500 order page — admin confirms payment and sends the file to the buyer's DM
- Tracking codes + status check page
- Admin dashboard: contact gain queue, separate VCF orders queue, review proofs, approve/reject, download approved VCF
- Admin settings: update WhatsApp channel & group links
- Neon PostgreSQL storage, optional Telegram notifications

## Quick start

```bash
npm install
npm start
```

Configure `.env` (see `.env.example`), then visit `http://localhost:3000`.
